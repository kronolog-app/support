This repository is used to track and respond to public issues, suggestions, and questions related to Kronolog.

Use this repository to:
- Report bugs
- Suggest new features
- Ask questions or get help
- Share general feedback

## How to Submit an Issue

1. Click on the **[Issues](https://github.com/kronolog-app/support/issues)** tab.
2. Click **New Issue**.
4. Fill out the form with as much detail as you can.
5. Submit ✅

> **Note**: This is a public space. Don’t include sensitive or private data.
